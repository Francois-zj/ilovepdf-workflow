# iLovePDF：Word → PDF → 水印 PDF

**中文** | [English](README.md) | [Français](README.fr.md)

一个面向 Windows 的批处理程序，使用 Python、tkinter 和 Playwright 操作可见的 **www.ilovepdf.com** 网页，先将 Word 转为 PDF，再添加文字水印。独立项目，与 iLovePDF 无官方关联；不使用 Microsoft Word 自带转换功能，也不调用 iLovePDF 开发者 API。

## 功能

- 手动选择 Word 来源、普通 PDF、水印 PDF 三个目录。
- 依次处理来源目录第一层的 `.doc`、`.docx`，然后为 PDF 加水印。
- 自定义文字、字体、字号、颜色、位置、透明度、旋转、图层和页码。
- 可在提交第一个 PDF 前检查网页中的水印参数，后续复用相同设置。
- 通过进度记录和文件校验跳过已完成任务；不会覆盖无法确认的已有结果。
- 原文件不修改；输出保留对应的文件基本名称。

## 环境要求

Windows、带 tkinter 的 **Python 3.10 或以上**、已安装的 **Google Chrome 或 Microsoft Edge**、网络连接。程序优先启动 Chrome，未安装 Chrome 时尝试 Edge。程序界面和命令窗口目前为中文；提供三种语言的文档，并不代表程序界面支持语言切换。其他系统尚未验证。

## 安装与使用流程

1. 在 GitHub 仓库点击 **Code → Download ZIP**，下载并解压。
2. 打开 CMD，输入 `python --version`；无法使用时再试 `py -3 --version`。两者都不可用时，安装 Python 3.10 或以上，勾选 **Add Python to PATH**。安装目录可以自定义。
3. 双击 `setup.bat`，等待出现 **Installation complete**。它会创建 `.venv` 并安装依赖；首次安装或依赖变化时运行即可。
4. 双击 `start.bat`。
5. 选择三个不同目录，例如 Word：`F:\WordInput`；普通 PDF：`F:\PDF`；水印 PDF：`F:\PDF_Watermarked`。来源目录必须存在，输出目录可由程序创建。
6. 填写水印文字并选择格式。默认文字是 `François QIN`，其他使用者应改为自己的文字。
7. 如需给每份文件的全部页面加水印，保持勾选 **每一页都加水印**。此时起始页和结束页不生效，每份文件按自己的实际总页数处理。
8. 选择第二阶段处理范围，点击 **开始处理**。
9. 浏览器打开后关闭 Cookie 提示；需要登录时在浏览器完成。准备好后，回 CMD 按回车。
10. 程序先完成全部 Word 转 PDF。如果勾选 **首个 PDF 提交前检查预览**，设置好第一个 PDF 的水印参数后会暂停。检查网页中的参数，满意后回 CMD 按回车；需要修改则输入 `q` 停止，重新启动并修改设置。这里检查的是网页参数，不是最终 PDF 效果。
11. 后续文件自动使用相同参数处理。保持浏览器和 CMD 打开；遇到网站提示，按命令窗口要求处理后继续。
12. 出现“全部完成”后，在输出目录打开 PDF 检查。最后按回车关闭程序。

## 页码和处理范围

- **每一页都加水印**：忽略两个页码输入框，适合页数不同的文件。
- 取消勾选后：起始页和结束页包含在处理范围内，对整批文件使用同一范围。例如 `1—2` 表示每份文件只处理前两页。
- 指定结束页超过某份 PDF 的页数时，会暂停提示；目前不能为每个文件单独指定范围。
- **全部 PDF**：处理普通 PDF 目录第一层的所有 PDF，包括目录中原来就有的文件。
- **仅本次 Word 对应的 PDF**：只处理与本次来源目录中的 Word 对应的 PDF。
- 每个成功任务后等待至少 20 秒，数值可以调高。Transparency 数值沿用网站选项含义。
- 平铺、加粗、斜体是可选效果；“下右”表示右下角；图层可选择内容上方或下方。

## 暂停、继续和已有文件

保留水印目录中的 `_workflow_progress.json`。使用相同目录和设置重新运行，来源和输出校验一致的任务会自动跳过。移动目录、修改原文件或水印参数后，已有输出可能无法确认；请使用新的相应输出目录，或先移走冲突结果，不会自动覆盖。

下载失败但浏览器仍能连接时，程序会提示在网页点击 **Download PDF**，然后回 CMD 按回车。浏览器断开时需重新启动。日志在 `_workflow_log.txt`，部分错误会保存 `_workflow_error.png`。

安装失败时先看 CMD 的报错。旧 `py` 启动器可能指向已删除的 Python；本包的安装脚本优先尝试可用的 `python`，再尝试 `py -3`。

程序不扫描子目录，跳过 `~$` 开头的 Word 临时文件。同名 `.doc` 和 `.docx` 必须先改名。需要修改水印参数时停止并重新启动，不要只在网页中手动修改。

文件会上传到 iLovePDF。登录、验证码、任务限额和网页变化可能需要人工处理，程序不会绕过。处理结果受网站和网络影响。作者本地 Windows 测试已成功完成一批 11 份文件，不代表所有环境都保证可用。
